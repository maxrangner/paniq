# Reference pictures

Concept art, sketches and photos that pin a model down go here, one file per
thing, named after it (`VendingMachine.png`, `VendingMachine-side.jpg`). Any
PNG or JPG will do: a photo of the real thing, a drawing on paper, a
screenshot of something with the right feel.

What helps the assistant most, in this order:

1. A straight-on **front view** and a **side view**, even rough.
2. **Something for scale** in the picture: a person, a door, a hand.
3. A note in the request saying which parts should move.

Keep single files under about 5 MB; the repository has no large-file storage
yet (see the decision log). How a picture becomes a model is in
[model-pipeline.md](../model-pipeline.md). The first picture here is
`WetFloorSign.jpg`, the photo the wet-floor sign was built from.
