# Paniq

Paniq is a darkly comedic 3D crowd-survival game inspired by the
indirect-control lineage of *Lemmings*. The player influences an autonomous
crowd during changing disasters and tries to save as many entities as possible.
They never command an individual directly: instead, they change the environment
and eventually may influence what people are capable of doing. Outcomes should
be surprising but explainable, so players can learn from a chaotic run and do
better on the next one.

## Foundation

- Engine: Unity `6000.3.24f1` (Unity 6.3 LTS)
- Language: C#
- Rendering: Universal Render Pipeline (URP)
- First target: Windows desktop

The project deliberately starts with ordinary GameObjects and C# scripts. ECS,
Burst, navigation, and other scale tooling are deferred until profiling proves
they are needed.

## New to game development?

You do not need prior Unity or programming knowledge to work on Paniq. The
project is intentionally being built in small, explainable steps. Before a new
technical tool or package is adopted, its current official documentation should
be researched and the decision recorded in
[`docs/technical-decisions.md`](docs/technical-decisions.md).

Three terms used in this project:

- **Unity** is the game editor and runtime used to build and run Paniq.
- **URP** is Unity's rendering setup: it draws the 3D world while keeping a
  later mobile version possible.
- A **GameObject** is Unity's basic scene object. The first playable slice uses
  these because they are easier to learn and inspect than large-scale systems.

When working with an assistant, expect a recommendation in plain language,
the reason it is suitable now, and clear instructions for anything you need to
do in Unity yourself.

## Open the project

1. Install Unity Hub and Unity `6000.3.24f1` with Windows Build Support. This
   installs the editor Paniq uses and lets it make Windows game builds.
2. In Unity Hub, select **Projects**, then choose **From disk**. In the Windows
   folder picker, select the `D:\dev\paniq` folder itself (not `.git`, `Assets`,
   or an individual file), then confirm. Do not choose **From repository**:
   Paniq already exists on this computer. Unity will import the project files;
   the first import can take a few minutes.
3. Allow Package Manager to resolve the packages in `Packages/manifest.json`.
   This downloads the small set of Unity features Paniq currently needs.
4. Select **Paniq > Project > Configure URP**. This creates the version-matched
   URP assets in `Assets/Paniq/Content/Rendering/` and assigns the pipeline in
   Graphics settings. The expected result is a confirmation with the new asset
   highlighted in the Project window. Commit the generated assets and updated
   project settings.
5. Open `Assets/Paniq/Scenes/Bootstrap.unity` and press Play. It loads the
   `FireReactionPrototype` scene: ten agents wander in one room, then react to
   an expanding central fire.

The URP setup command uses Unity's version-matched asset creator rather than
checking in fragile serialized assets generated by another editor version.

## Layout

```text
Assets/Paniq/
  Runtime/       Application, gameplay, simulation, and presentation code
  Authoring/     Scene and ScriptableObject configuration
  Content/       Placeholder and future game content
  Tests/         Edit-mode and play-mode tests
  Scenes/        Bootstrap and development scenes
docs/            Vision, goals, decisions, and workflow
```

## Validation

Run **Window > General > Test Runner** and execute EditMode and PlayMode tests.
These are automated checks: EditMode tests small pieces of code, and PlayMode
tests the game while a scene is running.
For performance work, profile a standalone Windows build and record the result
in the current milestone notes before introducing scalability technology.
